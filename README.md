# beemovie
Расширение для комфортного просмотра фильмов и сериалов 



Инструкция

Скачай архив beemovie.zip и полностью распакуй его в любое удобное место (например, в «Документы»). Важно: из самого архива расширение работать не будет!


Открой браузер (Chrome, Яндекс.Браузер, Opera или Edge) и перейди по ссылке chrome://extensions/ (в Opera это opera://extensions/).


В правом верхнем углу включи тумблер «Режим разработчика» (Developer mode).В левом верхнем углу нажмите кнопку «Загрузить распакованное расширение» (Load unpacked).


Выбери распакованную папку с расширением и нажмите кнопку «Выбор папки».


На панели браузера нажми на значок «пазла» и закрепи новое расширение «булавкой».
